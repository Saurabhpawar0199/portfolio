# Saurabh's portfolio (React + Vite)

## Run it on your computer
```bash
npm install
npm run dev
```
Open the address it prints (usually http://localhost:5173).

## Make it yours
Everything you see comes from `src/data.js`. Search for `TODO` and replace those values.
Put your resume PDF at `public/resume.pdf`.

## Build for production
```bash
npm run build     # creates the dist/ folder
npm run preview   # test the production build locally
```

## Deploy
Push this folder to a GitHub repository, then import it on https://vercel.com
(Framework preset: Vite, build command `npm run build`, output directory `dist`).
